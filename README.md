# TIMBER
Physical-model acoustic guitar instrument for macOS.

Rev 0.1:
- 24-voice MIDI polyphony
- Karplus-Strong / digital-waveguide-inspired plucked string engine
- velocity-dependent excitation
- pick-position excitation shaping
- string damping
- coupled body resonance surrogate
- resonance saturation
- HUMAN performance variation, naturally going to 11
- VST3, AU and Standalone universal macOS builds

Next: guitar-aware six-string fret/voicing allocator, strum engine, sympathetic resonance, hammer-ons, pull-offs, slides, palm mutes, harmonics, richer body modes and optional sampled attack layers.
